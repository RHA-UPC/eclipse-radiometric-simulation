## Por qué existe este acuerdo

El proyecto se publica bajo AGPL-3.0-only. Esa licencia obliga a cualquiera que
lo modifique y lo ofrezca por red a publicar su código, pero **no le impide
explotarlo comercialmente**: cualquiera puede montar un servicio de pago con él
mientras publique las fuentes.

Lo que el Titular quiere reservarse es distinto y más concreto: la facultad de
ofrecer el proyecto **bajo licencias distintas de la AGPL**, incluidas licencias
cerradas o comerciales. Esa facultad solo la tiene quien ostenta los derechos
sobre todo el código. En cuanto se fusiona una aportación externa sin cesión, el
proyecto la pierde de forma permanente, porque haría falta el consentimiento
individual de cada contribuyente para siempre.

Este acuerdo evita esa pérdida. No te quita el derecho a usar tu propio trabajo,
como se detalla en la cláusula 4.

## 12. Cómo firmar

Añade a cada commit de tu pull request la línea siguiente, con tu nombre real y
el correo con el que firmas:

```

```

Con `git` se automatiza así:

```bash
git config --local commit.template .github/commit-template.txt
```

La primera vez, además, escribe en tu pull request la frase:
